# Hollowbrook (play in your browser)

**Play: https://blakegoodstein.github.io/hollowbrook-play/**

This repository only holds the built web version of Hollowbrook, published with GitHub Pages.
It's updated automatically from the (private) game repository; don't edit it by hand.

- Saves stay in your browser.
- Phones and tablets get on-screen controls.
- Needs a browser with WebGL 2.
